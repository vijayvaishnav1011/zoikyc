API Integration

PAN Verify

Your dedicated PAN verification endpoint. Send pan + dob — ZoiKYC handles all CVL credentials securely on the backend.

POST https://zoikyc.com/api/pan/{{ company.client_id }}
Required Fields
"pan": "ABCDE1234F"
"dob": "DD/MM/YYYY"
Content-Type
application/json
No auth header needed
Sample PHP Integration 
// Send from your portal
$response = file_get_contents('https://zoikyc.com/api/pan/{{ company.client_id }}',
  false,
  stream_context_create(['http' => [
    'method'  => 'POST',
    'header'  => 'Content-Type: application/json',
    'content' => json_encode([
      'pan' => $pan,
      'dob' => $dob   // format: DD/MM/YYYY
    ])
  ]])
);
$result = json_decode($response, true);
// $result['success'], $result['full_name'], $result['status']
